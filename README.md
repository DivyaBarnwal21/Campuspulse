## 💡 Problem Statement
Every college student during placement season juggles 20+ company
applications across spreadsheets, forgets deadlines, and has no idea
if their resume will pass ATS filters. CampusPulse solves this.

## 🚀 What is CampusPulse?
A full-stack AI-powered career dashboard built specifically for Indian
college students — combining resume intelligence, application tracking,
and skill gap analysis in one authenticated platform.

## ✨ Features
| Feature | Description | Powered By |
|---|---|---|
| 🤖 AI Resume Analyzer | Upload resume → ATS score + company-specific tips | Gemini API |
| 📋 Placement Tracker | Kanban-style application status management | MongoDB |
| 🎯 Skill Gap Analyzer | Target a company → get exact missing skills + roadmap | Gemini API |
| 🐙 GitHub Feed | Track any developer's public repos and activity | GitHub API |
| 🌤️ Live Weather | Real-time weather for any city | OpenWeather API |
| 📰 Tech Headlines | Latest tech news feed | NewsAPI |

## 🏗️ Architecture

Frontend (React.js)
      ↓  Axios + JWT Interceptor
Backend (Node.js + Express) — MVC Pattern
      ↓  Mongoose
Database (MongoDB Atlas)
      ↓  REST calls
External APIs (Gemini, GitHub, OpenWeather, NewsAPI)


## 🛠️ Tech Stack
- **Frontend** — React.js, React Router, Axios, Context API
- **Backend** — Node.js, Express.js, MVC Architecture
- **Database** — MongoDB, Mongoose
- **Auth** — JWT, bcryptjs
- **AI** — Google Gemini API (gemini-1.5-flash)
- **APIs** — GitHub REST API, OpenWeatherMap, NewsAPI
